# CAT Studio — GitHub Pages preview

CAT Studio v3 supports CAT 1 (Walk), CAT 2 (Run), and CAT 3 (Fly).

## Website

- GitHub Pages: https://uchanet.github.io/cat-studio/
- Source: https://github.com/uchanet/uchanet.github.io/blob/master/cat-studio/index.html

This is the standalone STATIC edition. Drafting, editable fields, research planning, local browser storage, imported evidence, export of working JSON, and Copy Prompt work without a server. Live OpenAI chat, AI Auto-Research, and academic API calls need the separately deployed Node.js backend.

## Full AI edition

The complete source and local development server are in the CAT_Studio_AutoResearch_Copilot_v3_2026.zip previously provided in this conversation. Run with Node.js 18+ as documented in its README. Never commit an actual API key into GitHub or browser-side code. The local development server is not production-ready for public deployment.

## Course submission

This site drafts JSON compatible with the Fall 2026 official CAT form, schema 1.2. The professor's original form is required to build the final HTML submission. All empirical findings, research design classifications, database search counts, and effect sizes must be verified.
